# 헤븐씨드 주소 페이지

「2026 가을 친구초청잔치 with 미션」 교사용 앱으로 넘겨주는 **주소 한 장**입니다.

```
greatsong.github.io/heaven-seed  →  Apps Script 웹앱
```

Apps Script 웹앱 주소가 길어서(`script.google.com/macros/s/AKfy.../exec`) 외우거나 공유하기 어렵기 때문에 둡니다.

## 어떻게 동작하나

`<head>` 안에서 화면을 그리기도 전에 `location.replace`로 넘깁니다.
중간 안내 화면이나 기다림 없이 바로 앱이 열립니다.
`replace`라서 뒤로 가기를 눌러도 이 페이지에 갇히지 않습니다.

## 주소를 바꿀 때

고칠 곳은 `index.html` 맨 위 **`WEBAPP_URL` 한 줄**뿐입니다.
붙여 넣고 저장하면 1~2분 뒤 GitHub Pages에 반영됩니다.

주소가 비어 있거나 형식이 틀리면 넘기지 않고 안내 화면을 보여 줍니다.

앱 코드를 고쳐 **새 버전으로 배포**해도 주소는 그대로이므로, 여기는 한 번만 설정하면 됩니다.

## 이 저장소에 두지 않는 것

**학생 이름을 비롯한 어떤 데이터도 여기 두지 않습니다.**
이 저장소는 공개이고, 앱 코드와 명단은 별도(`heaven-seed`)에서 관리합니다.
여기 있는 것은 위 HTML 한 장이 전부입니다.
